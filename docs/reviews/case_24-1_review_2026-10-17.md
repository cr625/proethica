## 4. Findings

How this list was produced. Fourteen reading units, one per component or derived view, replayed the stored prompts and outputs against the case text and returned 318 findings, 143 of them factual. Ten lead findings were each checked by two verifiers (an evidence lens and a consequence lens). None was refuted, two were refined (D-20 and S-1 below record the refinements). Findings that describe one defect from several sides are merged here into one decision item, so that each item can be accepted or declined on its own. Decision items are numbered D-01 onward. Items marked SHARED touch a class or a reference-sheet entry that other cases use. They are flagged and not proposed for change unless decided otherwise. Reader finding ids in parentheses (for example PRI-01) refer to the full findings in the scratchpad file `findings_factual.md`.

Each item gives the records, the claim, the evidence, the basis, the proposed correction, what depends on the record, and the talk view it touches. Basis: case text means the stored value contradicts the opinion. Prompt instructions means the stored value violates a rule of the prompt that produced it or an ontology definition shown in it. Inference means the records disagree with one another or with the code path that produced them.

Nothing in this section has been applied. Sections 5 and 6 record the decisions and the changes.
