# Case Corpus and Sources

The case collection of ProEthica consists of published opinions of the Board of Ethical Review (BER) of the National Society of Professional Engineers (NSPE). ProEthica represents each opinion for inspection and comparison.

## The Board and the Code

The NSPE Board of Ethical Review considers ethical cases submitted by NSPE members, other engineers, public officials and members of the public. It reviews each case in the context of the NSPE Code of Ethics for Engineers and its earlier opinions, and publishes its opinions under numbered case identifiers such as Case 24-1. NSPE publishes the facts of each case with the parties identified by role (Engineer A, Client X).

## Source Material

Each case is taken from its published opinion page on nspe.org. The stored case text keeps the sections of the opinion: Facts, Questions, NSPE Code References, Discussion, Conclusions and, where present, a Dissenting Opinion. The case number, the date of the opinion and the NSPE subject tags are stored with the case. [Browsing Cases](browsing-cases.md) describes the case page.

The collection on proethica.org contains 119 opinions issued between 1958 and 2024.

## Attribution

Each case page carries the line "Source: National Society of Professional Engineers, Board of Ethical Review, Case NN-N" directly after the opinion text, linked to the opinion page on nspe.org. While the Engineering domain is selected, the footer of the application pages carries the NSPE note, which states the conditions for reprinting the opinions; **Full NSPE note** opens the complete text.
